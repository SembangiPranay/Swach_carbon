================================================================================
HOW TO RUN
================================================================================

1. Install dependencies:
   cd frontend
   npm install

2. Start development server:
   npm run dev
   → http://localhost:3000

3. Build for production:
   npm run build

4. Requirements:
   - Node.js 18+
   - Backend running on http://localhost:8000

================================================================================
API INTEGRATION
================================================================================

Endpoints Called:
  1. POST /calculate     → Start calculation
  2. GET /stream?id=xxx  → SSE streaming of agent thoughts
  3. GET /report?id=xxx  → Download PDF report
  4. GET /health         → Check backend (optional)

CORS Configuration:
  - All origins allowed (*)
  - GET, POST, OPTIONS methods
